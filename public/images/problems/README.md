# 스윙 문제점 이미지 폴더

이 폴더에는 각 스윙 문제 유형별 이미지를 저장합니다.

## 📂 이미지 파일 규칙

- **파일명**: `{typeName}.jpg` (예: `front-top-sway.jpg`, `side-down-casting.jpg`)
- **권장 크기**: 800x600px 이상
- **권장 형식**: JPG 또는 PNG
- **내용**: 해당 문제점을 시각적으로 보여주는 스윙 사진 또는 일러스트

## 🎯 필요한 이미지 목록

### 정면 카메라 문제 (Front View)
- `front-top-sway.jpg` - 백스윙 상체 흔들림
- `front-top-reverse.jpg` - 리버스 피벗
- `front-top-upright.jpg` - 상체 과도한 직립
- `front-top-armsync.jpg` - 팔 동기화 불일치
- `front-down-spinout.jpg` - 다운스윙 스핀아웃
- `front-down-slide.jpg` - 슬라이딩
- `front-down-dipping.jpg` - 디핑
- `front-impact-chicken.jpg` - 치킨윙
- `front-impact-flip.jpg` - 손목 플립
- `front-finish-balance.jpg` - 피니시 밸런스 불안

### 측면 카메라 문제 (Side View)
- `side-top-overswing.jpg` - 오버스윙
- `side-top-flat.jpg` - 플랫 스윙
- `side-top-steep.jpg` - 스팁 스윙
- `side-top-lowhand.jpg` - 낮은 손 위치
- `side-top-overrotation.jpg` - 과도한 회전
- `side-down-casting.jpg` - 캐스팅
- `side-down-overthetop.jpg` - 아웃사이드인
- `side-impact-scooping.jpg` - 스쿠핑

### 기본 이미지
- `default-problem.jpg` - 이미지가 없을 때 사용되는 기본 이미지

## 💡 이미지 준비 안내

1. 각 문제 유형별로 명확한 사진이나 일러스트를 준비합니다
2. 문제점이 잘 드러나도록 특정 프레임을 캡처합니다
3. 필요시 화살표나 원으로 문제 부위를 강조합니다
4. 파일명은 위 목록의 이름과 정확히 일치해야 합니다

## 🔄 현재 상태

현재는 `default-problem.jpg`만 존재하며, 나머지 이미지는 추가 예정입니다.
이미지가 없을 경우 자동으로 기본 플레이스홀더가 표시됩니다.
